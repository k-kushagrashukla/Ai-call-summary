# AI Call Summary
AI Call Summary is a web application that converts call recordings into clear and concise summaries using AI.
Instead of listening to long recordings, users can quickly get the key points and insights from conversations.

This project demonstrates how AI can be integrated into a Node.js backend with a simple web interface to automate call analysis.

## Features
- AI-Powered Summarization – Generates short summaries from long conversations
- Call Transcription – Converts conversation text to good results
- Fast Processing – Quickly processes transcripts using AI APIs
- Simple Web Interface – Clean UI built with HTML, CSS, and JavaScript

## Tech Stack
- Frontend
- HTML
- CSS
- JavaScript
- Backend
- Node.js
- Express.js
- AI Integration
- Groq API (for transcription and summarization)

## Use Cases
- Customer support call summaries
- Sales call insights
- Meeting recap automation
- Interview transcription and summarization
